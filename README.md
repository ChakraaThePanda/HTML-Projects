# HTML-Projects

Small games and tools that run right in your browser, each self-contained in its own subfolder.

**[Open the project page](https://chakraathepanda.github.io/HTML-Projects/)** to browse them all.

## Games

- [Key-Tiles](https://chakraathepanda.github.io/HTML-Projects/games/Key-Tiles/Key-Tiles.html) — reflex game where you clear streaming tiles in the right lane before they hit bottom.
- [MTG-Decklists](https://chakraathepanda.github.io/HTML-Projects/games/MTG-Decklists/MTG-Decklists.html) — a guessing game built from our past MTG decklists.
- [WTTG-K3RN3LC0MP1L3R](https://chakraathepanda.github.io/HTML-Projects/games/WTTG-K3RN3LC0MP1L3R/WTTG-K3RN3LC0MP1L3R.html) — practice minigame for Welcome to the Game's K3RN3LC0MP1L3R.

## Tools

- [Archipelago-Picker](https://chakraathepanda.github.io/HTML-Projects/tools/Archipelago-Picker/Archipelago-Picker.html) — weighted random picker for choosing what game to play next.
- [WoW-Forever-Macro-Creator](https://chakraathepanda.github.io/HTML-Projects/tools/WoW-Forever-Macro-Creator/WoW-Forever-Macro-Creator.html) — build WoW Forever macros with class spells, modifier keys, stances and a live 255 character preview.

Each subfolder has its own README with more details.
